# Contributing / 贡献

请先阅读 README、架构和隐私说明。变更应说明问题、行为变化、验证范围和限制。修改功能时同步中英文文档；不得将模型测试、云服务状态或截图模拟结果写成未经验证的事实。

Use synthetic fixtures. Keep credentials, runtime data, absolute personal paths and generated release binaries out of commits. Run checks appropriate to the change. Preserve the existing installer design unless the task explicitly changes it.
