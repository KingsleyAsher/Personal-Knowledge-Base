# memory-evolve 动态状态隔离补丁

[简体中文](README.md) · [English](README.en.md)

这是知识库 2.1.0 的独立配套补丁，适用于 `dsh-memory-evolve` 0.1.0 的特定代码基线。脚本按 SHA-256 严格检查；若不匹配，请保留现状并针对所装版本适配，不能强制覆盖。

## 修改内容

将会话标题、别名、身份及审查和写入提醒从稳定记忆快照中分离，以独立小消息按变化发送。记忆、用户档案、项目 KEY 正文和规则仍按原设置完整加载，不改动真实记忆数据、凭据或宿主核心。真实记忆更新仍可能触发完整快照；其他插件的变化也可能让宿主合并上下文重新注入。初次加载量与旧会话历史不因此减少。

## 应用

1. 下载 Release 附件 `memory-evolve-context-fix.zip` 并解压。
2. 完整退出宿主，确认插件目录是当前 `dsh-memory-evolve` 的实际源码目录。若多个 profile 共用此目录，补丁对它们均生效。
3. 先预览：`python apply.py --plugin-dir "插件实际目录"`。
4. 应用：`python apply.py --plugin-dir "插件实际目录" --apply`。脚本备份后只修改 `lib/index.js` 并增加 `lib/snapshot-state.js`。
5. 完整重启宿主，建议新会话观察。知识库安装包不会自动应用本补丁。

回退：`python apply.py --plugin-dir "插件实际目录" --rollback "脚本打印的备份目录"`。如果修改后的文件被再次编辑，脚本拒绝覆盖，需人工合并。上游插件升级可能覆盖此补丁，届时需要重新适配，不能用旧基线强装。

附件只包含最小代码改动、通用状态模块和安装脚本，不包含完整第三方插件、个人记忆或维护者设备路径。
