# Knowledge Base maintenance

- Update both `PROJECT-RECORD.md` and `PROJECT-RECORD.en.md` in the same change as any product feature, fix, or release. Record what changed and what was verified, and distinguish source changes from published installers.
- Keep the project title, language links, and current version at the top of both records. Put the newest entry first and preserve the historical entries below it.
- Before merging or publishing, verify that both records describe the same change and that newly packaged records match the release source.
