# 个人知识库 1.0.6

DSH 知识库主插件：目录绑定、条目管理与检索、资料导入、知识库界面、自定义流程、知识库预设及委派入口。日常只安装 `@local/dsh-knowledge-base` 一个包。

## 本版修复

- 同一导入任务在准备阶段即合并并发启动请求，同一宿主进程内的服务实例共享运行状态；任务清单与来源映射使用独立临时文件。
- 流程有参数时，点击「立即运行（新会话）」先填写本次参数，再点击「开始运行」。缺少必填值时不会新建会话，本次值不会改写流程默认值。
- 编辑保存保留流程能力与输出状态；已归档流程仍保持归档，点击「恢复」才恢复，并保留归档前的启用或停用状态。
- 非法参数对象返回校验错误；`constructor`、`__proto__` 等参数名按自身值解析与传输。
- 手机高级设置改为单列，默认值输入栏可换行排布；修正会话历史文案，合并重复刷新按钮。
- 导入轮询等绑定提交完成后再结束，并刷新当前库状态；异常概览响应显示具体错误。

## 流程工作区与更新

从知识库页签运行流程时，首次自动在知识库文件夹旁创建同级的「流程工作区」，并注册为 DSH 工作区。新会话明确使用 workspaceId；后续运行复用。草稿、下载和临时文件留在流程工作区，最终成果按流程输出规则落库。已有同名工作区指向其他位置、目录被文件或目录链接占用，或宿主服务不可用时明确报错。

流程通过 knowledge 预设的新会话运行，自动发送完整步骤、参数、时间窗和输出规则，切换到对话展示实时回复与工具调用。新运行保存在会话历史中，旧后台记录与取消入口保留。

插件启动后约 15 秒自动检查公开 GitHub 更新信息，此后每 6 小时检查一次；界面也提供「检查更新」。检查不发送知识库内容，不自动安装代码。网络失败明确显示错误，可手动重试。

## 安装与核对

通过 DSH「设置 → 插件」安装 `dist/local-dsh-knowledge-base-1.0.6.tgz`，升级保留既有绑定与运行数据。完全退出 DSH（包括托盘）再打开，知识库页签应显示「版本 1.0.6」。构建号与逐文件哈希见 `release-manifest.json`，发布件以 dist 中原 tgz 为准。

不需要另外安装旧委派网关或 H1；历史 profile 若仍启用旧网关，应迁移其配置并停用旧 bundle。同名知识库预设只保留一份。

解析页面仍为开发中。本包不包含 OCR/ASR 模型、Python 环境或推理服务；已有本地模型通过原工具使用。无 H1 的日常部署不提供系统级严格读隔离。
