# 个人知识库 1.0.3 · 流程会话运行修复（2026-10-19）

知识库 → 流程 →「立即运行（新会话）」现在创建使用 knowledge 预设的新会话，自动发送完整的流程步骤、参数和输出规则，并切换到对话视图。运行过程、工具调用、输出、停止和后续交流由普通会话提供。页面启动不再调用后台流程执行器，不再受逐步委派默认五分钟超时的限制；模型及工具本身仍可能超时或失败。

新运行保存在会话历史中。「后台记录」只展示旧执行器的运行记录，并保留取消旧任务的入口。模型工具 kb_flow 的后台执行能力仍保留。成功发送提示词只表示会话已接收任务，不代表流程已经完成。新的提示词会先要求核对知识库身份和已有产出，以减少重复写入。

本次版本为 1.0.3，知识库页签顶部显示宿主实际加载的版本与构建号，可手动刷新核对。安装新的 tgz 后需完全退出 DSH（含托盘）再启动；仅刷新页面无法加载新的宿主接口。离线与浏览器验收使用虚构库、模拟会话服务，并按本机 DSH desktop 0.2.1-rc.2 的接口核对；没有运行个人流程或访问正式库内容。

DSH 知识库主插件：目录绑定、建库与条目管理、索引检索、资料导入、知识库界面、自定义流程，以及知识库预设和委派入口。

日常部署只安装 `@local/dsh-knowledge-base` 一个包。知识库预设、客户端界面、流程、`agent_call` 和 `knowledge_request` 已随包提供，不需要另装旧的 `@local/dsh-agent-gateway`。DSH 官方组件由宿主提供。

升级时通过 DSH 现有插件安装入口安装 tgz，保留 profile 配置及 kb-state。若历史 profile 仍启用旧网关，应迁移其目标配置到本插件 gateway 并停用旧 bundle，避免主包委派被跳过；同名知识库预设也只保留一份注册。完全退出 DSH（含托盘）再启动，在 kb_status 核对版本与正式包记录的精确 buildId。

本次按用户已移除 H1 的日常部署交付，只安装这一个主包，不需要重新安装 H1 或其他副插件。本包不会自动安装或启用 H1；无 H1 时解析工具维持默认关闭，本次不启用无隔离解析开关。此部署不提供 H1 系统级严格读隔离。

本版本解析界面按产品决定标为“开发中”。已有本地 OCR、ASR 可以继续通过原来的本地模型或其他工具使用；主插件不包含模型权重、Python 环境或推理服务。本版不承诺安装主包后即可在解析界面直接运行模型。

个人定义的“信息报”等流程和知识库内容属于运行态数据，不随插件分发。本包不包含个人库内容或凭据。

本次基于此前完整正式源码，保留主题控件修复、流程表单和重建索引修复。变更涉及页面运行入口、流程提示词准备接口及说明文档。完整字节哈希、SRI、buildId 与验证范围见仓库 release-manifest.json。
