# 安装与使用

[English](WORKBENCH.en.md) · 中文

选择与文档库分开的应用安装目录。现有安装器要求空目录；已安装版本应保存内容并按安装器提示处理旧版本，再安装新包。卸载仅处理应用文件与快捷方式，个人资料与设置保留。

首次使用可以浏览示例资料，或在左下角资料库设置添加本机文件夹。移除资料库登记不会删除原文件；插件自己的绑定库受保护。真实库共享应通过客户端授权流程完成，不要手工复制索引数据库。

点击文件自动打开可用预览栏，最多四栏；拖动标签可移动或合并。开启编辑开关后修改，点击保存。Ctrl 加滚轮缩放内容，图片支持拖动平移。PDF 使用纵向连续页面。

Alt+F 打开可移动全局搜索；结果可拖入预览栏。关系网络支持选择节点、查看联系与旁侧预览。收件箱可整理归档、单个或批量管理索引；模型整理要求 DSH 在线。

右侧 DSH 栏可连接、重连、选择会话及 Agent 预设。输入框附近选择模型和推理强度；Enter 发送，Shift+Enter 换行。文件标签或选中文字可主动加入对话。连接和模型能力取决于宿主实际提供的接口。

不要把索引快照视为原文件备份。恢复前确认所选备份类型和目标。Office 预览与编辑有格式限制，重要复杂文档应保留原件。

共享源码更新见 [插件 2.4.3](../releases/plugin-2.4.13.md)：原件同步与 Windows 解析任务修复。已发布的客户端 1.0.3 安装器仍包含原先配套的插件 2.4.2，不因源码更新而替换其附件。

See [2.4.4 safe update and legacy transition](../releases/plugin-2.4.13.md). The published client installer remains 1.0.3.
