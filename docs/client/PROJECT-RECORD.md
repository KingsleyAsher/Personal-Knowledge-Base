# 设计与演进记录

[English](PROJECT-RECORD.en.md) · 中文

对应客户端 1.0.0，配套插件 2.4.0。更新日期：2026-11-04。

## 产品目标

以原有文件结构为中心提供独立桌面工作台。用户能够清楚地知道资料在哪里，在多个文档之间对照阅读、编辑和整理，并按需连接 DSH。文件树始终用于文件浏览；管理工具以可移动浮窗打开，并提供完整页面入口。

## 演进阶段

1. 兼容准备：建立插件基线、状态迁移和接口边界。
2. 共享内核：保留插件工具及界面门面，将业务实现拆入共享模块。
3. 共库服务：集中授权、写入、迁移与恢复，避免两个入口各自修改同一份索引。
4. 桌面工作区：实现文件树、多标签、最多四栏、内容预览与编辑，以及浅深色主题。
5. 联动与打磨：接入 DSH 会话、上下文附件和统计；改进浮窗、路径动画、PDF、主题及安装器。
6. 1.0.0 整理：客户端与插件 2.4.0 配套打包，提供可公开的源码与文档。

## 设计决策

- 分栏、标签和文件分别管理；空栏在关闭最后一个文件后收起，手动创建的新栏允许等待文件。
- 编辑由开关控制；关闭未保存内容时确认处理方式。
- 色彩主题同时定义框架、阅读面板、侧栏、选中态和文字，浅深色独立设计。
- DSH 对话上下文由用户主动拖入或选中文字添加。文件打开不等于自动发送给模型。
- 模型任务依赖宿主；本地浏览与管理保持独立能力。

## 源码地图

`apps/desktop/src` 是界面；`apps/desktop/main` 是桌面权限边界；`packages/kb-core` 与 `packages/kb-service` 是共享业务及服务；`src` 保留配套插件适配；`installer-design-b` 是现有安装器。

## 后续方向与限制

在线更新、保留数据的覆盖安装、更完整的 Office 保真度、跨版本兼容测试仍需继续完善。这些属于后续工作，不是 1.0.0 已交付承诺。每次发布同步更新本文与版本说明，验证范围以具体记录为准。
