## 2.4.10：安装待确认状态恢复（2026-11-05）

修复核对不到旧安装回执时，界面永久停在待确认、安装按钮保持禁用的问题。核对流程增加磁盘安装构建、当前安全安装操作和 profile 写锁信息；只有宿主明确没有旧请求、安装操作及写锁均不活跃且当前安装可校验时，才解除旧请求。单纯等待时间变长或接口失败不能触发解除。

已准备但尚未开始的安全事务可继续原事务，不创建第二次准备或重复安装。目标文件已经写入而宿主仍运行旧构建时，显示保存工作并重启；正在安装、无法校验或损坏状态继续拒绝盲目重试。

## 2.4.9：kb_flow 返回契约（2026-11-05）

修复共享模式 kb_flow 的返回结果缺少 action，导致宿主报 value.action 字段缺失的问题。共享服务与 Host 工具边界都按原请求补全动作；业务失败、断线与调用方校验失败也保留 action、原错误和成功状态，不放宽原输出校验，不把失败伪装成成功，不重放调用。

3 项定向测试通过，覆盖全部 8 种动作、实际注册的 Host 工具成功及失败返回，以及隔离真实 Windows 共享服务读取与业务失败。仅使用合成数据，没有重放正式用户流程。

另定位到记忆插件 1.0.4 在工具续步中仅从新输入查用户消息，可能以空快照替换已召回约定；该组件的 1.0.5 本地修复另行交付，不包含在此知识库包内，未公开发布或自动安装。合成课堂录音约定验证了持久保存、召回及解析完成后的上下文续接，未证明正式录音已自动生成笔记。

## 2.4.8：设置页的解析调用记录（2026-11-05）

修复共享服务把管理界面的只读请求当作普通会话的问题。设置页依据已认证连接的管理权限读取 OCR / ASR 执行任务和提交记录，不再按固定界面会话误过滤 Agent 发起的任务；资料可见性筛选仍然生效。普通模型工具和只读连接不因此获得跨会话管理权限，写接口仍要求管理授权。

3 项定向测试通过：在隔离的真实 Windows 共享服务中，由独立 Agent 会话调用本地合成 OCR / ASR 接口，设置页两种读取入口均能看到执行中、提交及完成后的记录；普通会话、只读连接与伪造参数不能越权。反例在修复前复现为空列表，修复后通过。样本和接口为合成数据，未读取正式知识库、调用外部付费服务或验证正式用户完整界面。

## 2.4.4：Windows 安全更新与失败恢复（2026-11-05）

- pnpm 只在隔离的清单副本中准备锁文件；新包先完成摘要、构建号、路径和文件校验，不让包管理器改写在线插件目录。
- 更新前通过管理员授权的停服协议检查其他连接、排队及运行中的解析、导入和流程任务；忙碌时延后。停服后核对清理回执及进程退出，再切换完整包目录。
- 原插件目录和清单保留在私有事务目录；切换或清单写入失败时回退并逐文件校验。中途退出的安装可从持久事务记录恢复，不把未知结果标为成功，不重复发起安装。
- 2.4.4 使用 release-manifest-v2.json。旧 release-manifest.json 停用安装分发，阻断旧更新器继续走不安全的原地安装。2.4.3 及更早版本首次过渡须退出宿主及连接客户端，使用本版过渡安装包；旧服务不支持停服协议时自动路径会拒绝接管。
- 成功安装后明确提示重启生效。嵌入模式或缺少安全停服能力时保持旧版，暂不自动安装。包带额外依赖、相对本地依赖或旧包已不完整等不支持的情况均停止，不擅自重建用户配置。

验证：35 项 Node 定向检查、5 项真实文件系统/真实 pnpm 事务测试，以及 1 个 Windows 运行服务升级复合场景通过。复合场景包括原始 2.4.3 服务的拒绝接管、额外连接和排队任务的延后、使用旧目录 Python 的协议服务退出、真实 2.4.3 包切换失败后逐文件恢复、成功升级重启和虚构原件保留。具备新停服协议的服务升级与未修改旧服务的首次过渡是两条不同路径。本次未在正式用户 profile 安装，也未验证真实模型或完整 UI。

## 产品目标

以原有文件结构为中心提供独立桌面工作台。用户能够清楚地知道资料在哪里，在多个文档之间对照阅读、编辑和整理，并按需连接 DSH。文件树始终用于文件浏览；管理工具以可移动浮窗打开，并提供完整页面入口。

## 演进阶段

1. 兼容准备：建立插件基线、状态迁移和接口边界。
2. 共享内核：保留插件工具及界面门面，将业务实现拆入共享模块。
3. 共库服务：集中授权、写入、迁移与恢复，避免两个入口各自修改同一份索引。
4. 桌面工作区：实现文件树、多标签、最多四栏、内容预览与编辑，以及浅深色主题。
5. 联动与打磨：接入 DSH 会话、上下文附件和统计；改进浮窗、路径动画、PDF、主题及安装器。
6. 1.0.1 整理：客户端与插件 2.4.1 配套打包，提供可公开的源码与文档。

## 设计决策

- 分栏、标签和文件分别管理；空栏在关闭最后一个文件后收起，手动创建的新栏允许等待文件。
- 编辑由开关控制；关闭未保存内容时确认处理方式。
- 色彩主题同时定义框架、阅读面板、侧栏、选中态和文字，浅深色独立设计。
- DSH 对话上下文由用户主动拖入或选中文字添加。文件打开不等于自动发送给模型。
- 模型任务依赖宿主；本地浏览与管理保持独立能力。

## 源码地图

`apps/desktop/src` 是界面；`apps/desktop/main` 是桌面权限边界；`packages/kb-core` 与 `packages/kb-service` 是共享业务及服务；`src` 保留配套插件适配；`installer-design-b` 是现有安装器。
