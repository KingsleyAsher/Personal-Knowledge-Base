# 版本与发布规则

客户端采用 x.y.z，当前为 1.0.0；插件独立版本当前为 2.4.0。配套不代表两者版本号必须相同。

发布时同步应用 package.json、锁文件、Windows 文件版本、构建清单和 Release 标签。构建号标识具体文件集合，SHA-256 标识下载文件。重新构建可能改变构建号。

预定更新来源为本仓库 Releases，尚未接入程序。先上传安装文件和校验值，最后发布版本清单；未验证下载与安装链路前不得声称自动更新可用。
