# 架构与共库边界

[English](ARCHITECTURE.en.md) · 中文

界面 → 受限 preload/IPC → Electron 主进程 → 授权共库服务 → 共享内核与库文件。

渲染进程不直接持有文件系统或服务凭据。服务核对库身份、授权与版本后执行写入；插件和客户端共用服务时使用相同业务内核。DSH 桥接处理会话、事件、任务回执及显式附件，未知写入结果不自动重发。

全文与向量索引属于当前库。关系结果使用库身份校验，切库后过期结果不能混入新库。共享云端向量配置可以由插件提供，也支持独立配置；配置内容不属于仓库。

DSH 或可选记忆插件离线时，本地功能继续可用；聊天、模型整理和共享全局记忆写入受在线能力限制。项目记忆保留既有范围，不汇总其他项目私有记录。

打包后的默认客户端配置位于用户目录下 `.dsh/knowledge-desktop-client`；源码开发使用独立运行目录。环境变量可指定测试目录。所有测试必须显式隔离数据与服务发现。
