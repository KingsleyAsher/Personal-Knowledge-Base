# 客户端版本说明

[English](RELEASE.en.md) · 中文



## 2026-11-05：插件 2.4.2 / 客户端 1.0.3

客户端反馈现已通过 Cloudflare Workers 与 D1 创建公开 GitHub Issue。用户无需登录 GitHub，提交前填写标题、正文并确认公开；只附带版本和构建号，不自动附带资料、日志或设备路径。凭据只保存在服务端 Secret 中。重复提交使用同一回执，结果未知时核对而不盲目重发；存在频率和每日总量限制。

跨盘回收修复：新回收项保存到资料库内部元数据目录；兼容旧回收项目，跨盘恢复经过复制及逐项校验；失败回执只有在确认源目录未变化且未移动时才标记失败。断线重连刷新保留已有页面快照。

插件 2.4.2 修复共库 Host 的正式更新检查与准备接口、1 MiB 发布清单读取及版本状态提示。共享 Host 的 Python helper 按内容摘要复制并验证到插件目录之外的持久运行目录，避免占用待替换的插件文件。沿用原有绑定、配置、解析记录和服务身份，不初始化、迁库或重发解析任务。独立离线安装器先阻止活跃客户端、备份并比较状态，再调用本机包管理器；真实安装及宿主激活由用户完成。

验证包括反馈接口及状态测试、真实部署测试 Issue #46 / #47（重复提交返回原 Issue）、隔离 C/D 双卷回收恢复、服务文件生命周期、Windows helper 存活时原包目录改名，以及 2.4.1 状态重开测试。独立安装器的包管理调用使用模拟；未以用户真实库或真实模型调用作评测，也不声称完整 Office 保真或所有网络可达。

两端分别使用 client-update.json 与 release-manifest.json，版本与 SHA-256 独立核验。客户端检查更新及校验下载已实现，自动覆盖安装与激活尚未实现。镜像附件在同步校验完成后可用。


## 客户端 1.0.2 · 2026-11-04

修复安装完成后首次启动的潜在阻塞：隔离安装器运行环境，首屏不再同步等待 IPC 或知识库服务；重复启动聚焦已有窗口。修正首次连接失败后的重试。

左右侧栏及预览分栏按帧预览宽度，松手提交布局；PDF、图片和浮窗等待尺寸稳定后更新，避免拖动反复重绘。拖动取消、失焦和栏目卸载均释放拖动状态。

反馈入口只把用户输入、版本和构建号复制到系统剪贴板，没有反馈服务器、上传接口或自动创建 Issue。请手动提交到本仓库 Issues。

验证：生产构建、22 项针对性测试、9 项界面检查、隔离安装后首次启动、连接失败重试，以及最终安装版本启动与拖动卸载检查通过。旧版间歇性白屏未稳定复现；不据此声称唯一根因或真实库负载性能。测试使用示例库，不包含个人资料或真实模型调用。

客户端检查更新和校验下载可用；自动覆盖安装与激活仍未完成。插件保持 2.4.1。


## 1.0.1 · 2026-11-04

整合本地文件工作区、最多四栏预览编辑、关系与管理浮窗、DSH 会话联动、独立浅深色主题及现有纸页绿安装器。配套知识库插件为 2.4.1，含可选记忆联动接口。

本地交付通过生产构建、版本/包文件校验及安装界面启动简查。未因版本改名额外进行真实模型或完整功能回归。源码公开与二进制 Release 发布分别进行。

当前没有接入客户端自动更新，也没有覆盖安装。复杂 Office 文件、云端服务与 DSH 版本兼容性存在边界，详见使用说明。

## 2026-11-04：同步版本与全自动更新策略

共享版本命名、比较和打包校验；插件跨大版本和预览候选更新均允许自动安装，保留通道偏好、包校验与忙碌/未知结果保护，不再弹更新确认窗口。安装后的版本说明规则不变。客户端在线下载安装尚未接入。本次只更新源码规则，不发布新包。
