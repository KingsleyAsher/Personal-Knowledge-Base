# 客户端版本说明

[English](RELEASE.en.md) · 中文

## 1.0.1 · 2026-11-04

整合本地文件工作区、最多四栏预览编辑、关系与管理浮窗、DSH 会话联动、独立浅深色主题及现有纸页绿安装器。配套知识库插件为 2.4.1，含可选记忆联动接口。

本地交付通过生产构建、版本/包文件校验及安装界面启动简查。未因版本改名额外进行真实模型或完整功能回归。源码公开与二进制 Release 发布分别进行。

当前没有接入客户端自动更新，也没有覆盖安装。复杂 Office 文件、云端服务与 DSH 版本兼容性存在边界，详见使用说明。

## 2026-11-04：同步版本与全自动更新策略

共享版本命名、比较和打包校验；插件跨大版本和预览候选更新均允许自动安装，保留通道偏好、包校验与忙碌/未知结果保护，不再弹更新确认窗口。安装后的版本说明规则不变。客户端在线下载安装尚未接入。本次只更新源码规则，不发布新包。
