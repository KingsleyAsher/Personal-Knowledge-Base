# 插件 3.1.3 · 文件树与周期维护性能

日期：2026-11-16。

- 文件目录与排除策略按文件身份缓存；列表只读取一次策略并预编译前缀匹配，条目使用已校验父目录直接 lstat。
- 目录列表在 15 秒内复用，并校验目录签名、策略签名、目录版本与隐私设置。
- 索引巡检先比较文件 stat 与 requests/import-sources 内容摘要，未变化时复用已持久化目录，不再全库哈希。
- 实测：687 项真实目录首次 376 ms → 32 ms、重复 0.8 ms；400 组排除策略的 250 项目录 819 ms → 49 ms；目录解析 16.5 ms → 0.4 ms；未变化巡检约 1.9 s → 0.1 s。
- 索引策略、架构、维护、分类、工作台、大库与服务集成检查通过，并新增策略匹配一致性、列表缓存失效与巡检复用检查。

发布制品：`local-dsh-knowledge-base-3.1.3.tgz`、`release-manifest-v2.json`、`SHA256SUMS`。客户端同步发布 2.0.3（未签名安装器，需空目录安装）。
