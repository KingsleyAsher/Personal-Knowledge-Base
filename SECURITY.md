# Security and privacy

Do not post credentials, document contents, chat histories, embeddings, personal paths or raw logs in public issues. Submit a minimal redacted reproduction and version information. For sensitive vulnerability details, contact the maintainer privately before disclosure; no dedicated security mailbox is configured here.

Opening a document does not automatically attach it to a conversation. Explicit attachments and configured cloud processing may transmit selected data to those providers. Runtime authorization and provider configuration govern that boundary.

Tests must use synthetic fixtures and isolated storage/service-discovery paths. Do not enable real model requests by default.
