已有资料怎么接入？+

在 DSH 设置中绑定目录。空目录可初始化；普通资料文件夹可以先查看导入计划，再选择原地接入或复制到收件箱。任务支持查看进度、中止与重试。需要 OCR 或 ASR 的资料，先解析，再按需要整理落库。

识别与转写，需要准备什么？+

在「识别与转写」中配置可用服务。支持本地 PaddleOCR-VL、Qwen3-ASR 等部署，以及已配置的 OpenAI 兼容、Qwen、百度原生接口与 CLI。插件不自动安装模型依赖；云端服务可能产生服务商费用，实际识别效果取决于模型、原件与运行环境。

自定义流程怎样帮我少做重复工作？+

把固定步骤、触发语、参数及输出规则保存为流程。下一次从流程页启动，会创建知识库会话并发送完整提示词。在会话中查看回复、工具调用与执行结果，也可以停止。实际执行需满足 DSH 宿主、知识库预设与授权要求。

怎样找回曾经整理过的内容？+

支持标题、标签、类型与正文全文检索，并沿来源定位原始资料。当前能力不是向量语义搜索。索引缺失或损坏时，可回退磁盘扫描；日常变动由后台增量维护，必要时可以手动重建。索引维护不修改正文或原件。

PERSONAL KNOWLEDGE / 1.1.6

从这里，开始积累。

  1. 在客户端安装插件

    将「下载插件」按钮的链接填入 DSH 插件管理器的安装源，由客户端自动下载；也可选择本地安装包 local-dsh-knowledge-base-1.1.6.tgz。

  2. 核对加载结果

    宿主支持时直接热加载；仅在提示需要重启时，完全退出 DSH（包括托盘）再打开。核对版本为 1.1.6。后续可在插件内点击「检查更新 → 立即更新」。

  3. 绑定一个本地文件夹

    打开「设置 → 个人知识库」，选择目录并点击「自动建库 / 识别」。先预览，再接入已有资料。

  4. 按需配置 OCR 与 ASR

    在「识别与转写」中配置已有本地环境或云端服务，再进行环境检查与解析验证。
