# 个人知识库 · 插件与客户端展示网页

[简体中文](README.md) · [English](README.en.md)

本目录是个人知识库插件与客户端统一项目的展示页。下载区仍描述已公开的插件安装包，不将源码版本冒充公开下载版本。直接打开 `index.html`，或使用任意静态 HTTP 服务预览；没有依赖安装或构建步骤。GitHub Pages 在 `main` 分支的 `website/**` 变更后自动部署。

页面介绍资料目录、关系网络、阅读与摘录、回顾、快速收集、受管 OCR／ASR 和回收站等能力，并提供正式版下载及安装指南。案例内容是预制展示资料，不执行模型推理；页面中的产品概念可视化不代表插件界面逐像素相同。

正式版安装包由 GitHub Release 提供，更新清单为仓库根目录的 `release-manifest-v2.json`。预览渠道清单为 `preview-manifest.json`；对应包在 `dist/`，并同步到 Gitee 与 GitCode。版本命名规则和旧版迁移说明见仓库根目录的 `VERSIONING.md`。
